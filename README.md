# 人柱愛麗絲 : 망가진 꿈 (멀티)

최대 8명 비대칭 호러. 1~3명은 **작은 꿈**, 나머지는 **다섯 번째 앨리스**.

## 폴더 구성

```
public/              사이트 (첫 화면 = 솔로 스토리 모드)
  index.html         솔로: 인주 앨리스 5장 + 쫄보 모드, 타이틀 메뉴에서 '멀티플레이'로 이동
  opening.mp3        솔로 오프닝 음악
  cute.mp3           솔로 쫄보 모드 음악
  multi/             멀티: 망가진 꿈 (주소 뒤에 /multi/)
    index.html       화면 · 로비
    game.js          1인칭 렌더러, 조작, 소리, 예측/보간
    shared.js        서버와 같이 쓰는 규칙 (맵 생성, 이동, 숫자 설정)
    config.js        게임 서버 주소
server/
  worker.js          실시간 방 서버 (Cloudflare Workers + Durable Objects)
wrangler.toml        Cloudflare 배포 설정
```

배포된 주소로 들어가면 솔로 타이틀이 나오고, 메뉴의 **멀티플레이 — 망가진 꿈**을 고르면 멀티 로비로 넘어갑니다. 쫄보 모드 설정도 같이 넘어갑니다. 멀티 첫 화면의 '← 혼자 하기'를 누르면 솔로로 돌아옵니다.

## 배포하기 (무료, 약 5분)

**추천: Cloudflare 한 곳에 전부 올리기**

1. [Node.js](https://nodejs.org) LTS 버전을 설치합니다.
2. 이 폴더에서 터미널을 열고:
   ```bash
   npm install
   npx wrangler login      # 브라우저가 열리면 무료 Cloudflare 계정으로 로그인
   npx wrangler deploy
   ```
3. 마지막에 나오는 주소(`https://injoo-alice.<내아이디>.workers.dev`)가 게임 주소예요. 친구들에게 이 주소를 보내면 끝입니다.

**선택: 화면만 Vercel에 올리기**

1. 위 1~3번으로 서버를 먼저 Cloudflare에 올립니다.
2. `public/multi/config.js`의 주소를 Cloudflare 주소로 바꿉니다.
   ```js
   window.INJOO_SERVER = 'https://injoo-alice.<내아이디>.workers.dev';
   ```
3. Vercel에서 새 프로젝트를 만들고 **Root Directory를 `public`** 으로 지정해 배포합니다. (빌드 명령 없음, 정적 사이트)

Vercel은 방마다 서버 하나를 붙잡아 두는 실시간 방 서버를 돌리기 어려워서, 방 서버는 Cloudflare에 둡니다.

## 내 컴퓨터에서 시험하기

```bash
npm install
npx wrangler dev
```
`http://localhost:8787` 을 브라우저 창 여러 개로 열면 혼자서도 여러 명으로 시험할 수 있어요.

## 규칙

- 방장이 방을 만들고 **꿈 인원(1~3)** 과 **최대 인원(2~8)** 을 정합니다. 4자리 코드로 참가합니다.
- '꿈 하고 싶어요'를 누른 사람이 먼저 꿈이 되고, 모자라면 무작위로 정합니다.
- 전원이 준비하면 방장이 시작할 수 있습니다.
- **앨리스**: 숲 곳곳에 있는 흔적 5개를 찾습니다(꾹 누르기).
  - ♠ 붉은 길 끝의 검
  - ♦ 무대 위의 오르골 (줍는 동안 소리가 숲 전체에 울림)
  - ♥ 성 안의 왕관
  - ♣ 초대장 두 장 (다과회 식탁, 남서쪽 공터)
- 흔적을 모두 찾으면 하늘에 문이 열립니다. 빛기둥에 들어가면 탈출입니다.
- **꿈**: 앨리스를 잡아(한 번에 한 명) 성 북쪽 안쪽의 감옥까지 끌고 가서 가둡니다.
  - 앨리스보다 조금 느린 대신 6초마다 대시를 쓸 수 있습니다.
  - 들려 가는 앨리스는 연타로 몸부림쳐 빠져나올 수 있고, 그러면 꿈이 2.5초 기절합니다.
- **감옥**: 다른 앨리스가 감옥 문 앞에서 3초 버티면 구출됩니다. 2분이 지나면 썩어 문드러져 성문 위에 걸리고(탈락), 그 뒤로는 관전합니다.
- **승패**: 13분 안에 한 명이라도 탈출하면 앨리스 승리. 시간이 다 되거나 앨리스가 전원 잡히면 꿈 승리.
- 꿈이 가까이 오면 앨리스에게 심장 소리, 숨소리, 비명이 들리고 화면이 일그러집니다.

## 조작

| | 컴퓨터 | 폰 |
|---|---|---|
| 이동 | WASD / 방향키 | 왼쪽 조이스틱 |
| 시점 | 마우스 (화면 클릭 후) · ←→ | 화면 오른쪽 드래그 |
| 행동 (잡기·가두기·줍기·구출·몸부림) | E 또는 Space | 행동 버튼 |
| 대시 (꿈) | Shift | 대시 버튼 |
| 지도 | M | 지도 버튼 |
| 채팅 | Enter | 채팅 버튼 |

## 숫자 바꾸기

`public/multi/shared.js` 맨 위 `CFG` 에서 속도, 대시 쿨타임, 감옥 시간, 제한 시간 등을 바꿀 수 있어요. 서버와 화면이 같은 파일을 쓰므로, 바꾼 뒤 `npx wrangler deploy` 한 번이면 둘 다 바뀝니다. Vercel을 쓰는 경우에는 Vercel도 다시 배포해 주세요.

## 무료 한도

Cloudflare 무료 플랜의 Durable Objects 한도는 하루 요청 10만 건, 실행 시간 13,000 GB-초입니다. 게임 메시지는 20개를 1건으로 셉니다. 8명이 꽉 찬 방 기준으로 하루 4시간 남짓 플레이할 수 있는 양이에요. 한도를 넘으면 그날은 접속이 거부되고, 매일 오전 9시(한국 시간)에 초기화됩니다.

## 음악 파일

솔로의 `opening.mp3`, `cute.mp3`는 직접 넣어주신 음원이라 배포하면 사이트를 아는 누구나 들을 수 있습니다. 빼고 싶으면 두 파일을 지우면 됩니다. 음악 없이 소리 효과만 나오고 게임은 그대로 돌아갑니다.
